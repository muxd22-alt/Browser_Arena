5 · Teach it

Play a match, download the .s1d, and the next hourly run imitates it.

  1. Set one side to you and play to the end of a match.
  2. Download the recording. It is one JSON line per decision, your exact states.
  3. Open a pull request adding it to games/<game>/data/human/.
  4. The next scheduled run weights human data highest and fits from it.

Reference implementation. The evaluator is ~20 lines per engine; see sdk/. Golden vectors in spec/golden.json prove the JS, C#, and GDScript evaluators agree.
